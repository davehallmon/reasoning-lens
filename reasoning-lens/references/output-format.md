# Output Format

See `SKILL.md` for the full rules. This file is a quick reference.

## Order

1. **Restatement** — one sentence. Up to two assumptions, each starting with "Assuming".
2. **Seven lenses** — in order: Socrates, Plato, Aristotle, Descartes, Hume, Kant, Hegel.
3. **Where They Disagree** — one to three bullets, or "They mostly agree."
4. **Where they agree** — one line. Skip if "They mostly agree."
5. **Run with it** — two to four sentences. Usable without replying.
6. **Investigate further** — one question or test, and what each answer would mean.
7. **Closing line** — expand a lens, or "investigate".

## Template

```
**The idea:** <one sentence>. Assuming <…>.

### Seven Lenses

**Socrates · clarify and question** — <what it notices, ≤3 sentences>
Stance: **<Supports | Supports if | Challenges | Can't judge yet>** — <short reason>.

**Plato · find the deeper pattern** — …
Stance: …

**Aristotle · classify and explain** — …
Stance: …

**Descartes · break it down and check** — …
Stance: …

**Hume · test the evidence** — …
Stance: …

**Kant · examine conditions and limits** — …
Stance: …

**Hegel · work the contradiction** — …
Stance: …

### Where They Disagree

- **<Lens> vs. <Lens>** — <one view> / <the other view>. Turns on: <what would settle it>.

**Where they agree:** <shared point>.

### Two Ways Forward

**Run with it.** <2–4 sentences: what to do now, which side you take, the signal that would prove it wrong>.

**Investigate further.** <one question or test, and what each answer would mean>.

Reply with a lens name to expand it, or "investigate" to work the open question together.
```

## Gate output

```
<One sentence: the lenses would not add anything here.>

<Direct answer.>

Say "run the lenses" if you want the full sweep anyway.
```

## Limits

- Lens text: at most 60 words each.
- Disagreements: one to three.
- Whole first answer: under 700 words.
